# dsh-appearance — DeepSeek Harness 外观插件

一款美化 DeepSeek Harness Web 界面的插件:

- 🎨 **三套配色方案**:默认 / 霓虹 / 清爽,自动适配系统明暗模式
- 🌈 **自定义渐变背景**:任意 RGB 颜色 + 渐变角度,自由组合
- 🖼️ **图片 / 视频壁纸**:导入本地文件,全屏展示,可调节透明度与暗化
- 💎 **玻璃输入框**:半透明 + 背景模糊 + 渐变边框,透明度/模糊强度可调
- 所有效果可以**任意叠加**,打造属于你的工作界面

---

## 安装

### 方式一:AI 助手一键导入(推荐,无需任何技术背景)

1. 打开 DeepSeek Harness Web 界面,进入任意会话
2. 把 `dsh-appearance.client.js` 的文件内容交给对话里的 AI 助手,并告诉它:

   > 把这个文件内容作为 `code.client` 定义一个 Cordis 插件,然后运行它。

3. 页面会弹出运行确认卡片,点击「**允许**」(仅首次需要,之后自动放行)
4. 完成!打开 **设置 →「外观」** 即可开始使用

### 方式二:管理员静态部署(面向部署运维)

让所有用户开箱即用,无需各自导入:

1. 确保部署中已安装 `@deepseek-ai/dsh-client-ui-appearance` 包(需先构建 `lib/client.js`)
2. 启动时挂载本目录的 `dsh-appearance.cordis.yml`:

   ```sh
   dsh web --patch ./dsh-appearance.cordis.yml
   ```

   或将文件内容合并进 `$DSH_HOME/.dsh/cordis.patch.yml` 固化
3. 重启 `dsh web`,插件随部署生效

## 使用方法

打开设置(侧栏底部齿轮)→「外观」,页面分为两个部分:

### 🎨 配色方案

| 方案 | 风格 |
|---|---|
| 默认 | Harness 原始配色 |
| 霓虹 | 深邃蓝黑 + 青色强调 |
| 清爽 | 柔和浅色 + 蓝色强调 |

点击即切换,立即生效,明暗模式自动跟随系统。

### 🌈 背景

**渐变背景**:

1. 点击颜色色块,打开取色器选色(或直接用 **R / G / B** 数字精确输入)
2. 拖动「角度」滑杆调整渐变方向(0–360°)
3. 点击「**应用渐变**」生效;调整后点击「**更新渐变**」即时替换

**图片 / 视频壁纸**:

1. 点击「上传图片」或「上传视频」,选择本地文件(支持 JPG / PNG / WebP / MP4 / WebM)
2. 拖动「透明度」滑杆调节背景明暗,「暗化」滑杆加深遮罩(视频壁纸建议开启暗化,文字更清晰)
3. 点击「移除」一键恢复

### 💎 对话框设置(玻璃输入框)

输入消息的对话框可以变成毛玻璃质感,所有调整**实时生效**:

- **玻璃输入框**(开关):总开关,关闭后恢复原始样式
- **透明度**(滑杆):10%–90%,数值越大背景越透
- **模糊强度**(滑杆):0–60px,数值越大雾化越强(0 为不模糊)
- **渐变边框**(开关):开启后为输入框加渐变描边(浅色模式白渐变、深色模式青紫渐变)

配合「背景」里的渐变或壁纸效果最佳——壁纸会透过输入框呈现清晰的毛玻璃质感。

## 注意事项

- 背景(渐变 / 壁纸)在**当前会话内**生效:刷新页面后需要重新设置一次
- 配色方案切换即时生效
- 壁纸视频为**静音循环**播放(浏览器自动播放策略),不会干扰操作

## 常见问题

**Q: 应用渐变 / 壁纸后,背景没有变化?**
A: 先关闭设置面板查看全局效果(设置面板会盖住背景);若仍无变化,确认插件运行卡片显示成功,必要时重新运行一次。

**Q: 上传的视频没有声音?**
A: 出于浏览器自动播放限制,壁纸视频固定为静音模式。

**Q: 换了一台设备 / 刷新后插件不见了?**
A: 动态导入的插件是会话级的,换设备或刷新后请按「安装 - 方式一」重新导入一次;长期使用建议让管理员用方式二静态部署。
